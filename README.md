# 大湾区活动指南

面向读者的静态活动页面，目前收录 2026 年 9 月 30 日–10 月 7 日大湾区电音与派对活动。

## 文件

- `index.html`：网站首页，内含样式，无需构建。
- `assets/posters/`：随站点发布的海报与活动封面；来源记录见 `sources.json`。
- 购票与活动详情跳转主办或票务平台；微信小程序入口需在微信中打开。

## 部署

可连接 EdgeOne Pages / Makers 或其他静态网站托管服务。

- 网站目录：仓库根目录 `.`
- 构建命令：留空
- 入口文件：`index.html`

使用未备案域名时，托管及加速区域选择中国大陆以外区域。

## 更新

修改 `index.html` 后提交并推送；已连接 Git 的托管服务可自动部署。
