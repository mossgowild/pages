# 大湾区活动指南

面向读者的静态活动页面，目前收录 2026 年 9 月 30 日–10 月 7 日大湾区电音与派对活动。

## 文件

- `data/events.json`：活动内容的唯一编辑入口，包括阵容、时间、曲风、票务、海报和资讯更新时间。
- `templates/index.html`：页面结构模板。
- `assets/site.css`：视觉与响应式布局；活动清单为按日期分组的单列手风琴行。
- `assets/hero.css`：首屏全宽 Drift Wall 海报墙与无脚本时的横向海报列表。
- `scripts/hero.mjs`：Drift Wall 海报墙（改编自 React Bits）：按屏宽分列、循环漂移，悬停与键盘聚焦提亮，聚焦时把海报移到墙的中部；`assets/hero.js` 为随站点发布的独立脚本。
- `scripts/topography.mjs`：全页 Topography 等高线背景（着色器改编自 React Bits Topography；线条按固定 1140px 尺度、以画布中心为基准，不随窗口宽高比拉伸）与页面顶部到筛选栏原位、日期标题与页脚文字背后的毛玻璃高斯模糊，使用 ogl 绘制；打包为 `assets/topography.js`，许可见 `assets/react-bits.LICENSE.txt`。
- `scripts/build_page.py`：使用 Python 标准库生成静态首页。
- `index.html`：生成后的发布入口，不直接编辑。
- `assets/filters.js`：吸顶筛选工具栏（React Bits Card Nav 的展开动效）、城市、场地、日期、曲风与开场时段的多选组合筛选；关闭 JavaScript 后仍展示完整清单。
- `assets/accordion.js`：活动清单的 React Bits Accordion Gallery（竖向）手风琴外观：每天第一条可见行展开，收起行平放、视差错位。
- `assets/event-detail.js`：活动详情卡片层：清单条目、首屏海报与 `#event-id` 地址打开同页详情，App Store 式从来源展开与缩回，×、下拉、Esc、遮罩与返回键关闭。
- `assets/posters/`：随站点发布的海报与活动封面（原图与 `*.thumb.webp` 轻量版）；来源记录见 `sources.json`。
- `scripts/build_posters.py`：用 `cwebp`（Homebrew `webp`）为 `sources.json` 里的每张海报生成短边 720px 的 WebP 轻量版并写入 `thumbnail`；新增或更换海报后、构建页面之前运行，重跑不改动已生成的文件。
- `assets/poster-preview.js`：活动详情头图的原生遮罩预览、原位缩放过渡与放大查看。
- `assets/copy-share.js`：点按内容本身即操作——地点的场地与地址调用系统分享（不支持时复制），小程序口令点按复制。
- `assets/scroll-motion.js`：活动封面滚动视差、日期标题的分层滚动与悬停边框光。
- `assets/pickers.js`：筛选用的自绘选择器，共用弹层外壳（胶囊触发器、`popover` 浮层或底部面板、清除与完成、焦点返回）：把带 `data-multi-select` 的 `select multiple` 增强为带搜索的多选列表（listbox 语义），把 `data-date-range` 中的开始、结束日期框增强为日历；原生控件隐藏并保留为表单取值。
- `assets/glass.js`：筛选控件胶囊、工具栏已选条件标签、详情关闭按钮、活动行与详情卡片边框共用的镜面反光（React Bits Specular Button 的 CSS 复刻，桌面鼠标 250px 内随指针转向增亮，触屏设备上随手机晃动亮起；活动行与详情卡片用 logo 四色光带，鼠标在卡片上时光带指向鼠标；标签随筛选重绘时自动接入）与 Chromium 上的 Glass Surface 折射（筛选工具栏、四张筛选卡片、空状态、场地与风格选择器、弹层搜索框、日期框与空状态按钮，按元素尺寸生成位移图）。
- `assets/brand/`：供图 Logo 的单色矢量与 favicon；`youyang-ravers-mono.svg` 为 1024×1024 透明画布，使用 `currentColor`，无位图或字体依赖，路径由原图用 potrace 重描（`favicon.svg` 为同一路径加深色圆角底，PNG 图标由它渲染导出）；`youyang-ravers-horizontal.svg` 为页眉用的横排 Logo（由原稿矢量组合：“有氧”横向加宽 115%，RAVERS 为其高的 84% 并垂直居中，整体斜切 15°，缩放与斜切已写入路径坐标，`currentColor`）。
- `assets/fonts/`：页眉专用的 Noto Sans SC Black 子集（只含标题与“大湾区”字符）及其 OFL 许可（`OFL.txt`），均取自 Google Fonts；拉丁展示字体 Syne 的 latin 与 latin-ext 可变字重子集（woff2，取自 Google Fonts，按 `unicode-range` 加载）及其 OFL 许可（`Syne-OFL.txt`）。均随站点加载，不请求外部字体服务。
- 购票与活动详情跳转主办或票务平台；微信小程序入口需在微信中打开。

## 部署

当前使用 Vercel 项目 `events`，生产分支为 `main`，域名为 https://events.cardioravers.com/。
GitHub 仓库按已确认设置保持公开。提交并推送生产分支后，由 Vercel 的 Git 集成部署。

`vercel.json` 跳过依赖安装，将已生成的 `index.html` 与 `assets/` 复制到 `public/` 并发布。
项目指令、模板、源数据与开发脚本不进入网站输出目录；发布前须完成下方本地检查。
`public/` 是忽略的部署产物，网站内容仍以根目录生成的 `index.html` 为准。

发布后确认部署状态、提交 SHA、线上 HTML 和资源文件一致；部署成功不等于大陆三网访问已验证。
